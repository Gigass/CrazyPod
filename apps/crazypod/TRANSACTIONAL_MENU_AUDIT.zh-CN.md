# CrazyPod 事务菜单交互审计

## 交互准则

CrazyPod 的菜单不再按照“任何选择都压入下一层页面”的旧 iPod 规则处理。
路由按用户任务分为两类：

- 内容空间：用户需要浏览、阅读、编辑或持续操作的界面，保留页面导航。
- 短事务：操作列表、单选设置、危险确认和一次性命令，显示在当前页面上方的弹层中。

短事务使用统一生命周期：

1. 当前页面保持原位并降低视觉权重。
2. 居中显示动作卡或选项卡。
3. 中键执行；Menu 返回上一张事务卡或关闭弹层。
4. 成功或失败时，原卡片切换为结果动画，不跳转到反馈页面。
5. 结果停留约 800 ms 后关闭；只有此时才刷新被修改的底层页面。

减少动态效果开启时，不播放缩放动画，但仍显示明确的成功或失败状态。

## 已迁移为弹层的路由

| 领域 | 弹层事务 |
| --- | --- |
| 设置 | 所有枚举型设置、语言、主页项目显示/隐藏、主页项目移动 |
| 个性化 | 图标、颜色、背景来源、布局值、Now Playing 主题、预设操作、预设编辑动作 |
| 便笺 | 未保存便笺操作、放弃确认、便笺操作、已删除便笺操作、删除/彻底删除/清空确认 |
| 书籍 | 书籍操作、删除确认、文字大小、页面主题 |
| 照片与视频 | 单个照片/视频删除确认 |
| 时钟 | 睡眠定时器选项与取消操作 |
| 锻炼 | 完成并保存确认、历史记录删除确认 |
| 日历 | 日程操作、删除确认 |

主页管理不再提供“上移/下移”二级菜单。选择“移动”后，原主页列表进入直接排序状态：
滚轮或左右键移动项目，中键或 Menu 完成并持久化。意外关闭产品层时也会提交当前顺序，避免内存顺序与持久化状态分叉。

## 保留为页面的路由

以下界面不是短事务，强行改成弹层会压缩内容或破坏返回语义，因此保留页面导航：

- 音乐列表、播放队列、专辑流、搜索结果和 Now Playing。
- 照片、视频、收藏、删除管理列表和照片详情。
- 设置分类页与 EQ Studio。
- 便笺编辑器、搜索、阅读器和已删除列表。
- 书库、最近阅读、收藏、章节、书签、统计、阅读设置和详情。
- 时钟、秒表、锻炼准备/进行/历史/摘要/详情。
- 日历月视图、日期列表、日程编辑器、日程详情和联系人详情。
- 预设库、预设重命名、壁纸文件选择和裁剪。
- Mini App 列表与运行界面。

## 结果反馈与失败语义

- 可确认成功的写操作显示绿色结果动画。
- 可检测失败的写操作显示红色结果动画，并且不执行成功导航。
- 删除使用“已删除/删除失败”；普通设置使用“已保存/失败”。
- 空便笺保存、预设应用/导出/更新/删除、便笺置顶/复制/恢复、书籍收藏、主题写入及各类删除都保留真实失败通道，禁止用成功动画掩盖失败。
- 选择导致进入真实内容页时直接导航，不伪装成“保存成功”。

## 后续新增菜单的约束

新增路由前必须先判断它是内容空间还是短事务。短事务应加入统一事务路由判定，复用动作卡、嵌套确认、结果动画和延迟刷新；不得再创建只包含几个命令的全屏二级页面。
