# GB / GBC 游戏

CrazyPod 的入口为桌面上的独立 **GB / GBC** 图标。游戏模拟功能独立于
Mini App 原生包加载器，不需要安装 `.cpk`。

## 放置游戏

将合法获取的 `.gb`、`.gbc` ROM 放入设备的 `/MiniApps/Games` 文件夹，
也可以放在 `/MiniApps/Games/GB`、`/MiniApps/Games/GBC` 中。
重新进入 GB / GBC 列表即会扫描。
最多列出 128 个文件；不递归扫描其他目录，不解压 ZIP，不支持 GBA。
固件和测试均不附带商业游戏或 Nintendo 启动 ROM。

`.cpk` 应用和播放主题仍直接放在 `/MiniApps`，游戏 ROM 放在其 `Games`
子目录，两种文件由不同的扫描器处理，不会互相干扰。
旧目录 `/Games` 不再扫描；已有 ROM 请手动移入新目录，存档位置和识别方式
不变，不需要移动存档。本次代码修改不会自动搬动设备上的文件。

## 操作

启动后先显示暂停菜单。转动滚轮选择，用中键确认。
选择“继续”开始游戏；也可以在此发送 START 或 SELECT。

真机触摸滚轮分成八个区域，从正上方向顺时针依次为：
上、A、右、START、下、SELECT、左、B。中键按下为 A，
外圈任意实体按键为 B，且可以与当前触摸区域组合。
长按中键一秒打开暂停菜单。

模拟器中 Menu / Play / 左 / 右对应四个方向，中键为 A，
滚轮事件为短按 B。START、SELECT 从暂停菜单发送。

画面以 240×216 等比例显示；核心按约 59.7 帧/秒调度，隔帧绘制。
游戏使用音频输出，运行时停止音乐；请在进入游戏前设置音量。
如果游戏加载失败，会恢复此前的音乐播放状态。

## 存档与退出

使用游戏自身的保存功能，再从暂停菜单选择“保存并退出”。
这里保存的是卡带电池 RAM 和 RTC，不是任意时刻的模拟器即时存档。
HOLD 锁定、USB 连接、系统关机或重启事件也会尝试保存并退出，
随后将系统事件交回 CrazyPod。

存档位于 `/.crazypod/gameboy/`，以 ROM 内容的 SHA-256 命名。
移动或改名 ROM 不影响读档，修改 ROM 内容则使用不同存档。
存档包含版本、长度、时钟和校验值，先写临时文件并同步，再替换旧档。
损坏或截断的存档会阻止启动，原文件不会被覆盖。
正常退出时若保存失败，会停留在暂停菜单并保留内存，可再次选择保存重试。
系统强制退出或断电仍可能丢失本次进度；不要在保存过程中断开电源。

请备份整个 `/.crazypod/gameboy/`。当前不导入其他模拟器的 `.sav`，
也没有即时存档、联机、作弊码或实体震动支持。

## 支持范围与验证

复用仓库的 Rockboy / gnuboy 核心，支持普通 ROM 及 MBC1、MBC2、MBC3、
MBC5 系列卡带。带震动的 MBC5 卡带按无实体震动运行。
Camera、MBC6/7、HuC 等特殊卡带会被拒绝。
标准 ROM 大小上限为 8 MiB；不保证所有游戏兼容或在真机上满速。

新增的主机测试使用自制指令程序，覆盖 GB/GBC 启动、画面输出、按键、
音频样本、卡带校验、电池 RAM、RTC、存档改名识别，以及写入、同步、
替换失败时的旧存档保护：

运行界面的主机测试还覆盖暂停菜单、保存失败后重试、HOLD 退出、
USB/关机/重启事件转交，以及加载失败后恢复音乐。它们使用硬件接口替身，
不替代真机上的按键、存储和音频测试。

```sh
sh tests/run-gameboy-host-tests.sh
# Windows 或不具备 sh 的环境也可以直接运行：
python tests/run-gameboy-host-tests.py
```

发布前仍需完整模拟器和 iPod6G 固件构建，并在真机上验证不同大小 ROM、
长时间音频、连续按键、正常读写档、HOLD、USB 和低电量关机。
